# Mockups และแบบร่างหน้าจอ

โฟลเดอร์นี้ใช้เก็บแบบร่างหน้าจอ ภาพตัวอย่าง และต้นแบบที่จัดทำก่อนเริ่มพัฒนาระบบจริง

## โครงสร้างโฟลเดอร์

- `images/` — ภาพตัวอย่าง เช่น PNG, JPG และ WebP
- `wireframes/` — แบบร่างโครงสร้างและลำดับการใช้งานหน้าจอ
- `prototype/` — ต้นแบบ HTML, CSS หรือ JavaScript ที่เปิดทดลองได้
- `archive/` — แบบเก่า แบบที่ยกเลิก หรือไฟล์ที่เก็บไว้อ้างอิง

## การตั้งชื่อไฟล์

ควรใช้ชื่อภาษาอังกฤษตัวพิมพ์เล็ก คั่นแต่ละคำด้วยขีดกลาง และระบุรุ่นเมื่อมีหลายแบบ เช่น:

```text
dashboard-overview-v1.png
device-detail-mobile-v2.png
alert-settings-wireframe.md
```

หาก mockup เชื่อมโยงกับแผนงาน ควรใส่ลิงก์อ้างอิงระหว่างไฟล์ mockup กับไฟล์ใน `docs/plans/` เพื่อให้ติดตามที่มาและการตัดสินใจได้ง่าย
