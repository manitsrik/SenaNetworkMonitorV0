# แผนการทำงาน

โฟลเดอร์นี้ใช้เก็บแผนก่อนเริ่มแก้ไขหรือพัฒนาระบบ เพื่อให้ขอบเขตงาน ขั้นตอน และวิธีตรวจสอบชัดเจนก่อนลงมือทำ

## วิธีใช้งาน

1. คัดลอกไฟล์ `TEMPLATE.md` แล้วตั้งชื่อเป็น `YYYY-MM-DD-ชื่อเรื่อง.md`
2. เขียนรายละเอียดเป็นภาษาไทยให้ครบเท่าที่จำเป็น โดยเฉพาะเป้าหมาย ขอบเขต และวิธีตรวจสอบ
3. ตรวจทานแผนก่อนเริ่มแก้ไขโค้ด
4. อัปเดตสถานะและผลการดำเนินงานระหว่างทำงาน
5. เมื่อทำเสร็จแล้ว ให้ย้ายไฟล์ไปไว้ใน `completed/`

ตัวอย่างชื่อไฟล์:

```text
2026-07-16-improve-task-scheduler.md
2026-07-20-add-device-alert.md
```

ชื่อไฟล์ควรใช้วันที่แบบ `YYYY-MM-DD` และใช้คำภาษาอังกฤษตัวพิมพ์เล็กคั่นด้วยขีดกลาง เพื่อให้เรียงลำดับและใช้งานกับเครื่องมือต่าง ๆ ได้ง่าย ส่วนเนื้อหาภายในให้อธิบายเป็นภาษาไทย

## ความหมายของสถานะ

- `ร่าง` — กำลังจัดทำแผน ยังไม่พร้อมเริ่มงาน
- `พร้อมดำเนินการ` — ตรวจทานแผนแล้วและเริ่มงานได้
- `กำลังดำเนินการ` — เริ่มแก้ไขหรือพัฒนาระบบแล้ว
- `ติดขัด` — มีปัญหาที่ต้องแก้ไขหรือรอข้อมูลเพิ่มเติม
- `เสร็จสิ้น` — ทำงานและตรวจสอบผลครบแล้ว
- `ยกเลิก` — ตัดสินใจไม่ดำเนินการต่อ พร้อมระบุเหตุผล

## หลักการเขียนแผน

- ระบุสิ่งที่จะทำและสิ่งที่จะไม่ทำให้ชัดเจน
- แบ่งงานเป็นขั้นตอนสั้น ๆ ที่ตรวจสอบความสำเร็จได้
- ระบุความเสี่ยงที่อาจกระทบระบบหรือข้อมูล
- กำหนดวิธีทดสอบก่อนเริ่มลงมือ
- บันทึกผลจริงและสิ่งที่ต่างจากแผนเมื่อจบงาน
